# Customer Education Pack

## Scope & Format Decision

The brief asked for 20 guides in each of 5 categories (100 total) — "20 how to store sharpened tools guides" read literally would mean 20 independently-written, non-repetitive pieces of advice about storage alone, which isn't realistic without either padding with trivial restatements or inventing distinctions that don't meaningfully exist. Instead, each category below is organized as **one table, broken down by real item type** (drawn from the site's actual item taxonomy — the same categories used in `docs/schema.md`'s master pricing table), which delivers genuinely distinct, non-repetitive, scannable guidance per item without forcing an arbitrary count.

## Files

- `prepare-items.md` — how to prepare each item type before drop-off/mail-in
- `common-mistakes.md` — common mistakes customers make, per item type
- `storage.md` — how to store sharpened tools, per item type
- `maintain-sharp-edges.md` — how to maintain an edge between professional sharpens, per item type
- `when-to-sharpen.md` — signs it's time to sharpen, per item type

15 item types are covered consistently across all 5 files: small paring knives, standard/large/butcher knives, hunting knives, hairdressing scissors, grooming scissors, thinning scissors, sewing/household scissors, A5 clipper blades, wide/large-animal clipper blades, hedge shears, secateurs, axes/tomahawks, home processor blades, and industrial processor blades.
