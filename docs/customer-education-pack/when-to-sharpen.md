# When to Sharpen (By Item Type)

| Item type | Signs it's time |
|---|---|
| Small paring knives | Slides off a tomato's skin instead of biting in; needs more pressure than it used to. |
| Standard/large/butcher knives | Crushing rather than slicing; visible white line reflecting light along the edge. |
| Hunting knives | Struggling on tasks it used to handle easily, or visible nicks/chips in the edge. |
| Hairdressing scissors | Pushing hair rather than cutting it cleanly; uneven results on a straight cut. |
| Grooming scissors | Pulling instead of gliding through fur; the animal reacting to discomfort during grooming. |
| Grooming thinning scissors | Uneven thinning results, or noticeably more hand effort required. |
| Sewing/household scissors | Fabric bunching into the blades instead of being cut cleanly; needing multiple passes. |
| A5 clipper blades | Pulling/tugging, more heat during use, visible unevenness along the edge. |
| Wide/large-animal clipper blades | Same signs as A5, often noticed first on thicker or matted coats. |
| Hedge shears | Crushing stems rather than cutting cleanly; more arm effort required for the same result. |
| Secateurs | Ragged rather than clean cuts on stems; noticeably more hand pressure needed. |
| Axes/tomahawks | Bouncing off wood rather than biting in; visible dents or rolled edge. |
| Home processor blades | Uneven or torn results instead of clean cuts; the motor sounding like it's working harder than usual. |
| Industrial processor blades | Inconsistent product results, increased motor strain, or a scheduled maintenance interval being due — don't wait for obvious failure. |

**General rule**: if you're pressing harder, going over the same spot more than once, or getting a worse result than you remember for the same task, that's the point to book a sharpen — waiting until a tool is completely unusable means more work is needed to restore it than a timely sharpen would have.
