# How to Prepare Your Items (By Item Type)

| Item type | Preparation |
|---|---|
| Small paring knives | Wash and dry before dropping off/posting. Wrap individually, tip protected. |
| Standard/large/butcher knives | Wash and dry. Wrap individually with cardboard folded over the tip for mail-in. |
| Hunting knives | Note any known chips, rust, or damage when you contact us. Send sheathed if possible; extra-wrap the edge if not. |
| Hairdressing scissors | Wipe down before drop-off/mail-in. Keep in a protective case or wrap individually if sending multiple pairs. |
| Grooming scissors | Same as hairdressing — wipe down, individual wrapping to avoid blades knocking together. |
| Grooming thinning scissors | Same as above; mention if you're unsure whether it's bevel or convex. |
| Sewing/household scissors | Standard wrapping is sufficient — no special prep needed. |
| A5 clipper blades | Remove from the clipper body, wipe off hair/oil, wrap individually. |
| Wide/large-animal clipper blades | Same as A5 — remove, clean, wrap individually so blades don't contact each other. |
| Hedge shears | Clean off dirt and plant residue. Keep pivot bolt finger-tight so it doesn't come apart in transit. |
| Secateurs | Same as hedge shears — clean, keep pivot finger-tight. |
| Axes/tomahawks | Protect the edge with cardboard/cloth. Note any handle damage. |
| Home processor blades | Wash and fully dry — food residue left in transit isn't pleasant to receive. Wrap individually if sending more than one. |
| Industrial processor blades | Contact first — size and packing vary too much for generic instructions; freight may be needed instead of standard post. |

**General rule for every item**: contact first to confirm pricing and satchel size, protect all points/edges, and include your return details inside the parcel, not just on the external label.
