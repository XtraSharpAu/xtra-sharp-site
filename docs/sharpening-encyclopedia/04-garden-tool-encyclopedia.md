## Garden Tool Sharpening Myths vs. Facts

- **Myth: "Garden tools don't need the same careful sharpening as knives."** Fact: the same water-cooled, temper-protecting process applies — see `docs/long-form-content/04-garden-tool-care.md`.
- **Myth: "A blunt axe is safer than a sharp one because it 'grips' better."** Fact: a blunt axe is more likely to glance/bounce off wood unpredictably rather than biting in cleanly — see `docs/troubleshooting-pack/garden-tools.md`.
- **Myth: "Sharpness is the only thing that matters for garden tools."** Fact: handle condition (cracks, looseness) is a separate, genuine safety issue independent of edge sharpness — see `docs/long-form-content/04-garden-tool-care.md`'s axe/tomahawk section.
