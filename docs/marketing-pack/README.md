## Notes on Flyers & Brochures

`flyers.md` and `brochures.md` contain **copy and layout specifications**, not finished print-ready graphics — this pack doesn't include a design/DTP tool. Hand these to a designer (or lay out in Canva/similar) alongside the site's actual brand colours (`#FFFFFF` background, `#1A1A1A` text, `#C00000` accent — see `tailwind.config.ts`) once real photography exists (`docs/image-handling.md`).

## Before Publishing Anything From This Pack

1. Confirm current pricing against `docs/schema.md`'s master table — if pricing has changed since this pack was written, every price mentioned here needs updating.
2. Anything marked as needing owner confirmation (see `docs/content-expansion-pack.md` for flagged items) should not be published until confirmed.
3. Add real photos once available rather than publishing text-only where a photo was implied.
