# Troubleshooting Pack

## Scope & Safety Note

The brief asked for 20 troubleshooting entries per category (100 total). Each file below lists every genuinely distinct, realistic issue that could be identified for that category without padding with trivial restatements of the same problem — this lands short of exactly 20 for some categories, and that's deliberate rather than an oversight (see `docs/customer-education-pack/README.md` for the same reasoning applied there).

**Safety-sensitive content (especially Processor Blades) is deliberately conservative.** These entries cover blade condition and cutting performance only. Anything touching equipment electrics, motor mechanics, or installation is redirected to "consult your equipment's manufacturer documentation or a qualified technician" rather than answered here — this project has no verified expertise in commercial equipment repair, and inventing confident-sounding technical/safety guidance in that area would risk real harm if a customer acted on it. See `docs/long-form-content/05-processor-blade-safety.md` for the same scope boundary applied to the safety article.
