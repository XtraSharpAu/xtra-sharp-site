# Garden Tool Troubleshooting

| Problem | Likely cause | What to do |
|---|---|---|
| Secateurs crushing rather than cutting stems | Dull edge | Book a sharpen |
| Secateurs/shears feel stiff or hard to close | Pivot too tight, or needs lubrication | Adjust pivot tension slightly; lubricate if dry |
| Secateurs/shears feel loose or wobbly | Pivot bolt has loosened | Tighten to finger-tight — not so tight the blades bind |
| Rust on the blade | Moisture/sap left on the tool without drying | Clean and dry thoroughly after each use |
| Hedge shears leaving ragged rather than clean cuts | Dull edge, or uneven wear along the blade length | Book a sharpen |
| Axe bouncing off wood instead of biting in | Dull or rolled edge | Book a sharpen |
| Axe head loose on the handle | Handle wear or shrinkage, separate from the edge | A safety issue — address the handle fit before continued use, regardless of edge sharpness |
| Handle cracked or splitting | Age, dryness, or impact stress | Inspect before use; a cracked handle is a safety issue even with a perfectly sharp edge |
| Tool harder to use than it used to be for the same task | Gradual dulling, often unnoticed day-to-day until it's fairly advanced | If pressure required has noticeably increased, it's likely time to sharpen |
| Sap/resin buildup affecting the blade's action | Not cleaned off after use on resinous plants | Clean promptly after use, especially after cutting sappy or resinous material |
| Uneven edge after home sharpening attempts | DIY sharpening with an incorrect angle or inconsistent technique | A professional sharpen restores a consistent, correct edge |
